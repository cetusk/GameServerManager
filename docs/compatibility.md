# v0.1.0 の対応状況と制約

このアプリはWindows x64上の同じPC内にある専用サーバーを管理します。現在は各ゲーム1件の登録に対応します。

## ゲーム別の状況

| ゲーム | 実装済みの正常停止方式 | Windows実ゲームでの確認 |
|---|---|---|
| Valheim | コンソール正常停止 | 起動・ゲームからの参加・正常停止・停止後の保存と再読込・バックアップ作成と履歴保持を確認 |
| ARK: Survival Ascended | RCONで保存・終了 | 未確認 |
| Conan Exiles | コンソール正常停止 | 未確認 |
| Windrose | コンソール正常停止 | 未確認 |
| Satisfactory | HTTPS API。新規設定の認証前はコンソール正常停止 | 未確認 |

5ゲームの設定登録、新規設定生成、起動・停止、更新、停止中のバックアップ／復元を実装しています。実装済みであることと、各ゲームの実機検証済みであることを区別しています。

Valheimもバックアップからの復元結果のゲーム内照合、新規作成からの一連の動作、今回のGUI設定変更すべての実機検証は未完了です。停止後の保存・再読込の確認は、ワールド内の全内容の照合を意味しません。

## 検証方法

- 人工データで設定変換、操作排他、対象照合、バックアップ／復元、失敗時の回復を検証
- Linux上の模擬GUIで画面操作を確認
- Windows向けRust型検査を実施
- Windows CIでテスト・ビルド・模擬GUI／空登録GUIの起動・ZIP作成を定義

型検査と模擬試験は実ゲーム試験の代わりではありません。CIの結果はリポジトリのActionsを確認してください。

## 主な制約

- 遠隔PC・コンテナー・Linux上の実サーバー管理には未対応
- 同じゲームの複数登録には未対応
- バックアップ・復元・設定変更は停止中のみ
- 定期実行、自動再起動、MODの自動ダウンロードには未対応
- 旧ツールのZIPバックアップのインポートには未対応
- Satisfactoryのclaim・初回セッション作成・参加パスワード変更はゲーム内のServer Managerを使用
- パス変更は参照先の変更のみ。既存のワールドやインストール先を自動移動しない
- 新規設定作成には空の設置先が必要。SteamCMD自体は事前に用意する

詳細は [操作ガイド](local-manager.md) と [サーバー設定](server-settings.md) を参照してください。
