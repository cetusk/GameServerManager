# 画面とアプリ設定

## ゲーム選択

最初に管理するゲームを選びます。「使用中のゲーム」には選択したゲームだけをカタログ表示します。「ゲームを追加・変更」で選び直せます。ゲーム名の下はサーバーのSteam Build、未インストール、または不明の表示です。

サイドバーのゲームをクリックすると管理対象を切り替えます。未登録のゲームでは「最初にサーバー設定が必要です」と案内し、設定の登録または新規作成へ誘導します。案内枠とタブの間には14pxの余白を設けています。

## サーバー画面

| タブ | 内容 |
|---|---|
| サーバー操作 | 起動・正常停止・更新／インストール・管理画面の再読み込み |
| サーバー設定 | 設定の新規作成・登録、基本設定と各種パスの編集 |
| ワールド設定 | Valheimのパラメーター編集、他ゲームの設定案内 |
| バックアップ | 停止中のバックアップ作成・復元内容の確認・中断した処理の復旧 |
| ログ | サーバーログのスクロール表示・全文コピー |

サーバー名の下に、処理名と実行中・完了・失敗のアイコンを表示します。作業履歴は件数が増えるとスクロールできます。起動失敗や今回のログで検出したエラーは、サーバー画面の上部に表示します。「稼働中」はプロセスの存在を表し、ゲームからの接続を保証する表示ではありません。

編集を開いた後に別タブ・ゲーム・画面へ移動したりウィンドウを閉じたりすると、変更の有無にかかわらず確認が出ます。「編集を続ける」で入力を維持し、「変更を破棄して離れる」で移動します。確認中は背景操作を無効にします。サーバー設定・ワールド設定・新規作成が対象です。

## 言語とテーマ

初期言語は日本語です。左下のLanguageから日本語・Englishを切り替えます。ゲーム名、サーバー名、パス、ログ本文、OSの診断メッセージは翻訳しません。

左下の歯車から「アプリ設定」を開きます。テーマはターコイズ・ブルー・バイオレットの3種類で、すべてダークモードです。

## アプリ設定

- **通知**：作業完了・失敗の画面内通知、Windowsの通知音。通知をオフにしても履歴は記録します。
- **前回の記憶**：前回のゲーム・タブを開く設定。初期値は両方オフです。サーバーや処理を自動再開する機能ではありません。
- **設定の移行**：テーマ・言語・通知・記憶のJSONエクスポート／インポート。サーバー登録・パスワード・ワールドは含みません。
- **SteamCMD**：共通パスの保存、既存exeの選択、Valve配布ZIPのダウンロード・配置。新規サーバー設定に初期入力します。個別パスはゲームごとの欄で変更できます。
- **保存先**：管理データの保存先を確認・変更。すべてのサーバーを停止し、処理を完了してから切り替えます。元のデータは移動・削除しません。
- **アプリ情報**：アプリのバージョン、管理データの保存先、ライセンスとSlintの出典表示。

設定は初回画面・アプリ設定で選択した、または起動引数で明示したdata-dir内の `local-preferences.json` または `mock-preferences.json` に保存します。既存の保存済み設定は更新時も維持します。

操作の詳細は [サーバー管理](local-manager.md)、入力項目と保存の制約は [サーバー設定](server-settings.md) を参照してください。

## exe直接起動と初回設定

引数なしのexe起動は実管理モードです。保存先が未設定なら、管理データの用途を説明する案内画面でフォルダーを選択・確定します。日英切り替えは初回画面にもあります。既存フォルダーを選べばその管理データを開き、新しいフォルダーを選べば新規環境になります。選んだ保存先はWindowsユーザーごとに記憶します。記憶した場所が見つからない、読み込めない場合はエラーを画面に表示し、選び直せます。ゲームサーバーを自動起動することはありません。

SteamCMDの共通パスは同じ管理データ内の`local-steamcmd.json`に保存します。表示・通知の設定JSONとは別で、アプリ設定のエクスポート／インポートには含みません。ダウンロード・検証・展開・設定保存・ファイル選択はワーカーで実施し、画面は進捗と結果だけを受け取ります。処理中は管理画面の再読み込み・保存先変更・終了と、サーバーへの新しい操作を待機させます。詳細は[SteamCMD](steamcmd.md)。
